# Rules for packages/design-tokens
- Never edit tokens.json by hand. It must stay byte-identical to the approved design system's file (hash in README.md, checked by a test). Changes start in the design system (D029).
- This is the ONLY place colors are written down. The no-raw-color lint rule is off here and nowhere else.
- dist/ is generated by `pnpm --filter @meetapp/design-tokens build`; never commit or edit it.
- The contrast check must never be loosened to make a build pass; fix the token in the design system instead.
